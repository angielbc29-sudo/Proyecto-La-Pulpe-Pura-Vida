# 🛒 La Pulpe Pura Vida

**La Pulpe Pura Vida** es una aplicación de escritorio hecha en **C++17 con Qt 6** que digitaliza el trabajo diario de una pulpería costarricense de barrio, que normalmente se lleva en cuadernos y con calculadora.

El sistema permite:

- 📦 **Productos e Inventario:** ver el catálogo, registrar y editar productos y recibir alertas cuando algo se está agotando.
- 💰 **Ventas y Cobro:** armar el carrito, calcular el total con IVA, cobrar en efectivo y dar el vuelto.
- 🧾 **Comprobantes e Historial:** consultar las ventas realizadas y generar el ticket o la factura en PDF, TXT o HTML.
- 👥 **Usuarios y Permisos:** iniciar sesión con roles (Administrador, Cajero y Auditor) y llevar una bitácora de quién hizo cada acción.

Proyecto final del curso **EIF201 - Programación I** (II Ciclo 2026), Universidad Nacional de Costa Rica, Sede Regional Chorotega - Campus Nicoya.
